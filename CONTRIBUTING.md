# Contributing

Thank you for considering a contribution. The repository is currently in planning, so implementation pull requests will not be accepted until the critical architecture review gate is closed.

## Before opening work

1. Search existing issues and discussions.
2. Open an issue for behavior changes or new integrations.
3. State the official interface or documented contract an integration relies on.
4. Separate observed facts, inferences, and unverified assumptions.

## Pull requests

- Keep each pull request focused on one accepted issue.
- Include tests or explain why deterministic verification is not possible.
- Do not include credentials, private conversation content, user-specific absolute paths, or copied vendor databases.
- Do not claim that activity means progress, delivery means acceptance, or an agent self-report means completion.
- Update user-facing documentation when behavior changes.

Implementation setup instructions will be added after the reviewed architecture baseline is published.
